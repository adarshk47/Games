Master G app icon - generated by Flutter code, not hand-drawn.

Source of truth: lib/core/ui/app_logo.dart (MasterGLogoPainter).

Files here (1024x1024):
  app_icon.png             full icon (legacy launcher icon)
  app_icon_background.png  adaptive icon background (purple gradient + puzzle motif)
  app_icon_foreground.png  adaptive icon foreground (gold G; flutter_launcher_icons adds a
                           16% inset, which places the image in the 66dp safe zone)
  app_icon_monochrome.png  white G for Android 13 themed icons
Store art: store_assets/play_icon_512.png, store_assets/feature_graphic_1024x500.png

To regenerate after changing the painter:
  flutter test test/tool/render_icons_test.dart --dart-define=RENDER_ICONS=true
  dart run flutter_launcher_icons
